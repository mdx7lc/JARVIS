          Knowledge Graph

          Not connected

          No graph index exists

          A knowledge graph needs real relationships between real notes (links, backlinks, or explicit connections) produced by a backend indexer. JARVIS has no vault index yet, so there is nothing truthful to draw — this view stays empty rather than rendering invented nodes.

          • Required: an indexed note store (see Obsidian Vault).
          • Required: a relations endpoint (nodes + edges derived from real links).
          • Then: an SVG force/cluster layout with zoom, pan, fit, and node inspection.

          The graph view will activate automatically once the backend provides real data. No vector database is part of this phase.
